4. HALLAZGOS Y MEJORAS
----------------------
1) list() usaba localeCompare con locale en cada comparacion del sort
   -> se reutiliza un Intl.Collator: 353 ms -> 8.3 ms (43x).
2) Buscar por sku recorria todo el almacen (O(n))
   -> indice Map sku->id: getBySku 365x, create 35x, update 57x mas rapido.
3) La traza mostro que CREATE TABLE IF NOT EXISTS corria en CADA peticion
   (48% del tiempo de GET /api/postgres/users)
   -> se ejecuta una sola vez: 1249 -> 1778 peticiones/s (+42%),
      p95 12.25 -> 8.78 ms, tiempo de servidor 4.34 -> 1.92 ms.
4) GET /api/products no tiene paginacion: con 2.060 productos tarda 54.6 ms
   en vez de 5.9 ms. Queda documentado como recomendacion.
